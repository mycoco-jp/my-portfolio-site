制作範囲
デザイン・コーディング
使用技術
HTML / CSS / JavaScript

制作目的

初めての海外旅行を検討しているユーザーの不安を解消し、旅行プランの提案から予約につなげることを目的として制作。

ターゲット

卒業旅行やハネムーン、家族旅行など、初めての海外旅行を検討している幅広いユーザーを想定。

工夫した点

ユーザーが必要な情報へすぐにアクセスできるよう、ファーストビュー直下に主要なコンテンツへの導線を配置。
国内・海外をタブで切り替えられるようにし、情報を整理しながら比較・閲覧しやすいように設計。
丸みのある見出しやデザイン要素を取り入れ、旅行への期待感や楽しさが伝わる雰囲気を演出。
